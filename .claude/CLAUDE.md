# Проект: M2M Роботы — Симулятор → Реальный мир

## Цель
Взаимодействие двух роботов (M2M) в реальном мире после обучения одного из них в симуляторе Unity с помощью PPO (RL).

---

## Среда

- **Трасса**: препятствия ≥ 20×20×20 см, которые нужно объехать
- **Финальная зона**: открытое пространство с желтым мячиком на полу (случайная позиция)
- **Желтый мячик** детектируется готовой моделью YOLO

---

## Роботы

### Робот-скаут
- **ОС**: ROS 2
- **Сенсоры**: камера + лидар
- **Задача**: объехать препятствия (лидар), найти мячик через YOLO, верифицировать через LLM, отъехать в сторону

### Робот GFS-X
- **ОС**: ROS 1
- **Сенсоры**:
  - Монокулярная камера (вращающаяся)
  - Ультразвук (вперёд)
  - ИК-датчики: вперёд, влево, вправо (по 90°)
  - ИК-датчик в манипуляторе (gripper)
- **Задача**: объехать препятствия, найти мячик (он скрыт), захватить манипулятором
- **Ограничение**: конфигурацию робота менять нельзя

---

## Порядок действий

1. **Скаут стартует** → объезжает препятствия (лидар) → ищет мячик (YOLO)
2. **Мячик найден** → скаут подъезжает, центрирует мячик в кадре → отправляет фото в **Yandex LLM API**
3. **LLM возвращает JSON** с подтверждением: мячик это или нет
4. **Скаут получает подтверждение** → отъезжает в сторону (данные GFS-X не передаёт)
5. **GFS-X стартует** → объезжает препятствия → ищет мячик в ограниченном пространстве → захватывает манипулятором (gripper можно поставить на пол сразу, чтобы мячик «вкатился» внутрь)
6. *(Опционально)* GFS-X возвращается обратно

---

## Обучение

- **Симулятор**: Unity (модель GFS-X предоставлена)
- **Метод**: PPO (Reinforcement Learning)
- **Цель обучения**: сопоставить входы сенсоров → управляющие команды робота

---

## Принципы работы над проектом

- Сначала — **бейзлайн**, усложнения только после явного запроса
- Детали уточняются **по ходу** → быть готовым к перестройке
- При выборе подхода — **предлагать несколько вариантов**, спрашивать какой применить
- Нюансы и актуальная информация будут поступать итеративно — учитывать её приоритетнее начальной

---

## Ключевые технологии

| Компонент | Технология |
|---|---|
| Симуляция | Unity + ML-Agents |
| RL-алгоритм | PPO |
| Навигация скаута | ROS 2 + лидар |
| Управление GFS-X | ROS 1 |
| Детекция мячика | YOLO (готовая модель) |
| Верификация | Yandex LLM API (JSON ответ) |
| M2M коммуникация | Скаут НЕ передаёт данные GFS-X напрямую |
